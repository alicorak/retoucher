# retoucher

Your coding agent, inside Figma. Leave notes on your Figma layers; Claude Code, Codex or Cursor edits the file and answers in the same panel.

Retoucher is installed as an agent plugin plus a Figma plugin, not from npm. This package only prints the setup steps:

```bash
npx retoucher          # how to set it up
npx retoucher prompt   # the setup prompt to paste into your agent
```

Figma plugin: https://www.figma.com/community/plugin/1696122599848660328/retoucher

Website: https://retoucher.alicorak.com · Source and docs: https://github.com/alicorak/retoucher
